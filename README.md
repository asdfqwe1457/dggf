分销关系绑定

佣金规则与结算
佣金可按商品、分类、活动设置比例，支持固定金额与百分比。分销等级可根据业绩自动升级，不同等级享受不同佣金比例与团队奖励。订单完成后，佣金进入待结算；售后期结束后，转为可提现。提现支持微信零钱、支付宝、银行卡，系统自动生成对账单与税务报表。对于企业，需注意佣金税务处理与发票合规。

合规边界与风险控制
